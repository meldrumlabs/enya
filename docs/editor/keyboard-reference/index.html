Keyboard Reference

Enya uses vim-style keybindings. This page provides a complete reference of all available shortcuts.

Navigation

Section titled “Navigation”
KeyAction
h/j/k/lMove between panes
Ctrl+w h/j/k/lMove focus to split
TabNext pane
Shift+TabPrevious pane

Pane Management

Section titled “Pane Management”
KeyAction
xClose focused pane
mMaximize focused pane
FToggle fullscreen for focused pane
ZToggle zen mode (hide chrome)
eEdit focused pane
cvCycle visualization type
yyShare/yank focused pane

Finder and Search

Section titled “Finder and Search”
KeyAction
Space+fOpen unified finder (metrics, alerts, commits)
:Open command palette
?Show keyboard shortcuts

Go-To Commands

Section titled “Go-To Commands”
KeyAction
gdGo to definition
gaGo to alert
gfFloat focused pane

Time Range Presets

Section titled “Time Range Presets”

Press t followed by a key:

KeyAction
t 5Last 5 minutes
t 1Last 15 minutes
t 3Last 30 minutes
t hLast 1 hour
t 6Last 6 hours
t dLast 24 hours
t wLast 7 days
t cCustom time range

Leader Keys (Space)

Section titled “Leader Keys (Space)”
KeyAction
Space+fOpen unified finder
Space+aOpen/focus agent panel
Space+dToggle diagnostics overlay
Space+hShow home page
Space+bToggle project sidebar
Space+pOpen plugins overlay
Space+tOpen time range picker

Visual Multi-Select

Section titled “Visual Multi-Select”
KeyAction
Ctrl+vEnter visual-multi mode
v or EscapeExit visual-multi mode
j/kExtend selection
xClose all selected
eMulti-edit selected panes
rRefresh all selected
yyShare selected panes

Window Movement

Section titled “Window Movement”
KeyAction
Ctrl+w h/j/k/lMove pane in direction
Ctrl+w t h/j/k/lMerge pane into tabs with neighbor

Other

Section titled “Other”
KeyAction
ctCycle through themes
uUndo last action
EscapeClear focus / exit modal

Command Palette

Section titled “Command Palette”

Press : to open the command palette.

CommandAliasAction
:versionShow version and build info
:split <h/v>spSplit view (horizontal/vertical)
:vsplitvsVertical split
:quitqQuit workspace
:writewSave workspace
:settingssetOpen settings (AI, styling, connections)
:screenshot [path]ssTake a screenshot
:shareShare workspace as URL
:terminaltermOpen a terminal pane (native only)
:sqlOpen a SQL pane (native only)
:trace [id]trOpen a tracing pane
:logslogOpen a logs pane
:floatflFloat focused pane
:dockdkDock all floating panes
:tutorialtutOpen interactive tutorial
:sync gitSync git operations (native only)
