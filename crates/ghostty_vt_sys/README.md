# ghostty_vt_sys

Low-level FFI bindings to [ghostty](https://github.com/ghostty-org/ghostty)'s VT library, compiled via Zig.

## Origin

This crate was vendored from [gpui-ghostty](https://github.com/Xuanwo/gpui-ghostty) by Xuanwo.

## Build Requirements

This crate requires **Zig 0.15.2** to compile the ghostty VT library. The build script will attempt to download Zig automatically if not present.
