# egui_nerdfonts

Nerd Fonts icons for egui.

## Why Vendored?

This crate is vendored from [bernsteining/egui_nerdfonts](https://github.com/bernsteining/egui_nerdfonts) to stay in sync with Enya's egui version (currently 0.33.x). The upstream crate may lag behind egui releases.
