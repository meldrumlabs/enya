# AI Agents

Enya integrates AI agents directly into the editor. Agent panes appear alongside your metric charts, allowing you to chat with AI while viewing your data. The editor exposes your Prometheus metrics and codebase context to agents, enabling intelligent observability workflows.

## Agent Panes

Agent panes are first-class citizens in the viewport. Create an agent pane with:

- `Space+a` keyboard shortcut

The agent pane provides a chat interface where you can ask questions about your metrics and codebase. Agents can render inline charts and source code previews directly in the conversation.

## Slash Commands

Type `/` in the agent input bar to access slash commands—structured prefixes for common investigation workflows:

| Command | Description |
|---------|-------------|
| `/investigate` | Deep-dive analysis with correlations and anomaly detection |
| `/diff` | Compare metric states between two time ranges |
| `/query` | Generate PromQL from natural language |
| `/explain` | Explain what the current query or chart shows |

Combine slash commands with `@` mentions:

```
/investigate @http_requests_total why is it spiking?
```

## Metric Mentions

Type `@` to mention metrics in your prompts. The editor provides fuzzy autocomplete for all metrics from your connected Prometheus instance.

## What Agents Can Access

When an AI agent works with Enya, it has access to:

### Prometheus Metrics
- All metric names from your connected Prometheus instance
- Label names and values for each metric
- Query results and time-series data
- PromQL syntax and functions

### Codebase Context
- Source code where metrics are instrumented
- Alert rule definitions in YAML files
- Git commit history correlated with metric changes
- Function and file context around metric definitions

## Example Workflows

### Incident Investigation

Ask an agent to help investigate a metric spike:

> /investigate @http_requests_total spiked at 3:00 AM. What commits were deployed around that time?

The agent can:
1. Query the metric data around that time
2. Find git commits in the time range
3. Locate where `http_requests_total` is instrumented in your code
4. Correlate the spike with specific code changes

### Understanding Metrics

> What does @db_connections_active measure and where is it generated?

The agent can:
1. Find the metric instrumentation via tree-sitter analysis
2. Show the surrounding code context with syntax highlighting
3. Identify the function and file where it's recorded
4. Render inline source code previews in the chat

### Query Assistance

> /query 99th percentile latency grouped by endpoint

The agent can:
1. Know your available metrics and labels
2. Construct a valid PromQL expression
3. Execute the query and show an inline chart

## Supported Providers

Enya adopts the ACP (Agent Communication Protocol) and supports:

- **Claude Code** — Anthropic's coding agent
- **Codex** — OpenAI's coding agent

Configure your API key in settings to enable agent features.

## Configuring for AI Agents

### 1. Connect to Prometheus

```
:connect http://localhost:9090
```

This gives agents access to metric names, labels, and query execution.

### 2. Configure Codebase

In your workspace TOML:

```toml
[codebase]
url = "https://github.com/your-org/your-repo"
branch = "main"
```

This enables:
- Go-to-definition (`gd`) for metrics
- Git commit markers on charts
- Alert rule discovery (`ga`)
- Source code context for agents

### 3. Index Your Codebase

When you load a workspace with codebase config, Enya automatically:
- Clones the repository
- Parses source files with tree-sitter
- Indexes metric instrumentation points
- Scans for alert rule definitions

## Best Practices

### Be Specific
Instead of "why is this slow?", ask "/investigate @request_duration_seconds what code paths contribute to this histogram and what changed in the last week?"

### Use Slash Commands
Slash commands provide structure to your prompts and help agents understand your intent.

### Reference Metrics by Name
Use `@` mentions so agents can look up specific metrics with their labels.

### Use Workspace Context
Load a workspace with both Prometheus and codebase configured so agents have full context.

## Native Only

Agent features require the native desktop app. The web version does not support AI agents due to API key handling and ACP protocol requirements.
