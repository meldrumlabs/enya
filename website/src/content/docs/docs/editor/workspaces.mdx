# Workspaces

Workspaces are TOML configuration files that define a collection of panes with queries and an optional i3-style tiling layout. Workspaces are stored in `~/.enya/workspaces/`.

## Workspace Commands

| Command | Aliases | Description |
|---------|---------|-------------|
| `:mksession [name]` | `mks` | Save current workspace |
| `:source [name]` | `so` | Load a workspace |
| `:workspaces` | `ws` | Open workspace finder (fuzzy search) |
| `:share` | | Share workspace as URL |

## Basic Structure

```toml
[workspace]
name = "my-dashboard"
description = "Production monitoring dashboard"

[connection]
endpoint = "http://localhost:9090"

[view]
theme = "dark"

[time]
preset = "1h"  # Options: 5m, 15m, 30m, 1h, 6h, 24h, 7d

[[panes]]
query = "sum(rate(http_requests_total[5m])) by (method)"
name = "Request Rate"
visualization = "timeseries"

[[panes]]
query = "histogram_quantile(0.99, rate(http_request_duration_seconds[5m]))"
name = "P99 Latency"
visualization = "stat"
```

## Pane Configuration

Each pane in the `[[panes]]` array supports:

| Field | Type | Description |
|-------|------|-------------|
| `query` | string | PromQL query expression |
| `name` | string | Display name for the pane |
| `visualization` | string | Chart type: `timeseries`, `stat`, `gauge`, `bar`, `sparkline`, `heatmap` |
| `aggregation` | string | Aggregation function (optional) |
| `granularity` | string | Time granularity: `1m`, `5m`, `15m`, etc. |
| `unit` | string | Display unit: `ms`, `%`, `req/s`, etc. |

## i3-Style Layouts

Workspaces support i3-style tiling layouts with horizontal/vertical splits and custom proportions.

### Layout Types

- `horizontal` — Split panes side by side
- `vertical` — Stack panes top to bottom
- `tabs` — Group panes as tabs

### Pane References

Panes are referenced by their 0-indexed position in the `[[panes]]` array:

```toml
[[panes]]          # Index 0
query = "up"

[[panes]]          # Index 1
query = "process_cpu_seconds_total"

[[panes]]          # Index 2
query = "process_resident_memory_bytes"
```

### Simple Layout

```toml
# Creates: Pane0 | Pane1 with equal widths
[layout]
type = "horizontal"
children = [0, 1]
```

### Nested Layout

```toml
# Creates:
# +---------------------+-----------+
# |                     |  Pane 1   |
# |      Pane 0         +-----------+
# |                     |  Pane 2   |
# +---------------------+-----------+

[layout]
type = "horizontal"
shares = [2.0, 1.0]
children = [
    0,
    { type = "vertical", children = [1, 2] }
]
```

### Layout Properties

| Property | Type | Description |
|----------|------|-------------|
| `type` | string | Container type: `horizontal`, `vertical`, or `tabs` |
| `children` | array | Pane indices (numbers) or nested container objects |
| `shares` | array | Proportional sizing (defaults to equal `1.0` for each child) |

## Codebase Integration

Connect a git repository to enable go-to-definition and commit markers:

```toml
[codebase]
url = "https://github.com/your-org/your-repo"
branch = "main"
```

With codebase configured:
- Press `gd` on a pane to jump to where the metric is generated in source code
- Press `ga` to view alert rules referencing the metric
- Git commits are displayed as markers on time-series charts

## URL Sharing

Share your workspace or individual panes via URL:

- **Full workspace**: Use `:share` command to copy a URL containing your entire workspace
- **Single pane**: Use `yy` (vim-style yank) on a focused pane to share just that query

URLs use compact binary encoding (postcard + LZ4 compression + base64) and can be opened at `enya.build/editor`:

- `?workspace=...` — Full workspace with all panes and layout
- `?pane=...` — Single pane with just one query

## Example Workspaces

### Simple Dashboard

```toml
[workspace]
name = "simple"

[connection]
endpoint = "http://localhost:9090"

[[panes]]
query = "up"
name = "Service Health"
visualization = "stat"

[[panes]]
query = "rate(http_requests_total[5m])"
name = "Request Rate"
visualization = "timeseries"
```

### Complex Layout

```toml
[workspace]
name = "production"
description = "Production monitoring with split layout"

[connection]
endpoint = "http://prometheus.internal:9090"

[time]
preset = "1h"

[[panes]]
query = "sum(rate(http_requests_total[5m])) by (method)"
name = "Requests by Method"
visualization = "timeseries"

[[panes]]
query = "histogram_quantile(0.99, rate(http_request_duration_seconds_bucket[5m]))"
name = "P99 Latency"
visualization = "stat"
unit = "ms"

[[panes]]
query = "sum(rate(http_requests_total{status=~\"5..\"}[5m]))"
name = "Error Rate"
visualization = "stat"

[layout]
type = "horizontal"
shares = [2.0, 1.0]
children = [
    0,
    { type = "vertical", children = [1, 2] }
]
```
