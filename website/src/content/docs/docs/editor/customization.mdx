# Customization

Enya supports customization of fonts and themes to match your preferences.

## Fonts

Configure the editor font in your workspace or global settings:

```toml
[view]
font = "JetBrains Mono"
font_size = 14
```

The editor uses your system fonts. Popular choices for observability work:
- **JetBrains Mono** — ligatures, clear distinction between similar characters
- **Fira Code** — ligatures, compact
- **IBM Plex Mono** — clean, professional
- **Departure Mono** — the default Enya font

## Themes

Enya ships with a dark theme optimized for long sessions. Theme configuration:

```toml
[view]
theme = "dark"
```

Available themes:
- `dark` — Default dark theme with emerald accents
- `light` — Light theme for high-ambient environments

### Chart Colors

Customize the color palette for chart series:

```toml
[view.colors]
series = ["#10B981", "#3B82F6", "#F59E0B", "#EF4444", "#8B5CF6"]
```

## Configuration File

Global settings are stored in `~/.enya/config.toml`:

```toml
[view]
font = "JetBrains Mono"
font_size = 14
theme = "dark"

[view.colors]
series = ["#10B981", "#3B82F6", "#F59E0B", "#EF4444", "#8B5CF6"]
```

Workspace-specific settings in your workspace TOML override global settings.
