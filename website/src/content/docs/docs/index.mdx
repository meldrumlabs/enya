# Welcome to Enya Documentation

AI-Native Observability Editor — explore your Prometheus metrics with the power of vim-style navigation and AI agents.

## Get Started

- **[Getting Started](/docs/docs/getting-started/)** — Install and run Enya
- **[Editor Guide](/docs/docs/editor/)** — Learn keyboard shortcuts, commands, and workflows

## Key Features

- **AI-Native** — AI agents with access to both your metrics and codebase
- **Prometheus Compatible** — Works with any Prometheus-compatible endpoint
- **Codebase-Aware** — Jump from metric graphs to source code
- **Keyboard-Driven** — Neovim-inspired workflows with vim-style navigation
- **i3-Style Layouts** — Flexible tiling workspaces defined in TOML
