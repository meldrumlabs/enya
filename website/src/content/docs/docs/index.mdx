# Enya Documentation

A keyboard-first multi-tool editor that brings together code, observability, databases, and terminals.

## Built for Builders

Enya is designed for the engineers writing the code, instrumenting metrics, responding to pages, and debugging production issues. Navigate your entire stack like you navigate code—with vim-style keybindings, a command palette, and workspaces defined in TOML.

## Core Concepts

- **Keyboard-Driven** — Neovim-inspired navigation with `h/j/k/l`, `:` commands, and leader keys
- **Multi-Tool** — Code, metrics, logs, traces, SQL, terminals — all in one interface
- **Codebase-Aware** — Jump from observability data to source code with tree-sitter analysis
- **AI-Native** — Connect Codex or Claude Code to analyze data and create visualizations
- **i3-Style Layouts** — Flexible tiling workspaces with splits, tabs, and proportional sizing
