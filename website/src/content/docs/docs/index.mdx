# Enya Documentation

A keyboard-first observability editor that connects metrics, code, and AI.

## Built for Builders

Enya is designed for the engineers writing the code, instrumenting metrics, responding to pages, and debugging production issues. Navigate metrics like you navigate code—with vim-style keybindings, a command palette, and workspaces defined in TOML.

- **[Quick Start](/docs/docs/getting-started/quick-start/)** — Install and run Enya in minutes

## Core Concepts

- **Keyboard-Driven** — Neovim-inspired navigation with `h/j/k/l`, `:` commands, and leader keys
- **Codebase-Aware** — Jump from metric charts to source code with tree-sitter analysis
- **AI-Native** — Connect Codex or Claude Code to analyze metrics and create visualizations
- **Prometheus Compatible** — Works with Prometheus, Thanos, Mimir, VictoriaMetrics, and more
- **i3-Style Layouts** — Flexible tiling workspaces with splits, tabs, and proportional sizing
