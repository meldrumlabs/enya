# Enya Documentation

A keyboard-first multi-tool editor that brings together code, observability, databases, and terminals.

## Built for Builders

Enya is designed for the engineers writing the code, instrumenting metrics, responding to pages, and debugging production issues. Navigate your entire stack like you navigate code—with vim-style keybindings, a command palette, and workspaces defined in TOML.
