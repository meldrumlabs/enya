# Quick Start

Get started with Enya in just a few minutes.

## Try in Browser

The fastest way to try Enya is in your browser — no installation required:

**[Launch Web Editor →](/editor)**

## Download

Download Enya for your platform:

- **[macOS](/downloads/enya-macos.dmg)** — macOS 10.15 or later
- **[Windows](/downloads/enya-windows.exe)** — Windows 10 or later
- **[Linux](/downloads/enya-linux.AppImage)** — AppImage, .deb, .rpm

## Connect to Prometheus

Once Enya is running, connect to your Prometheus instance:

1. Press `:` to open the command palette
2. Type `connect http://localhost:9090` (or your Prometheus URL)
3. Press Enter

You should see "ONLINE" in the status bar once connected.

## Explore Metrics

Open the metrics finder to start exploring:

1. Press `Space+m` to open the fuzzy finder
2. Type to search through your metrics
3. Use arrow keys or `j`/`k` to navigate
4. Press `Enter` to add a metric to your workspace

## Basic Navigation

Enya uses vim-style navigation:

| Key | Action |
|-----|--------|
| `H`/`J`/`K`/`L` | Move focus between panes |
| `:` | Open command palette |
| `Space+m` | Open metrics finder |
| `?` | Show all keyboard shortcuts |
| `e` | Edit focused pane query |
| `Ctrl+Enter` | Run query |

## Save Your Workspace

Save your current layout as a workspace:

1. Press `:` to open command palette
2. Type `mksession my-dashboard`
3. Press Enter

Load it later with `:source my-dashboard`.
