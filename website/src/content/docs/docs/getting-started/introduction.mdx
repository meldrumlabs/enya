# Introduction

Welcome to Enya! This introduction will help you understand what Enya is and how it can bring deep observability to your data systems.

## What is Enya?

Enya is an embeddable observability agent designed specifically for data systems. It instruments your data pipelines, databases, and streaming applications to provide real-time visibility into data flow, quality, and performance. Unlike traditional observability tools that focus on infrastructure metrics, Enya understands data semantics and provides insights at the data layer.

## Key Features

- **Embeddable by Design**: Lightweight agent that runs within your data systems, not as a separate service
- **Data-Aware Observability**: Tracks data lineage, quality metrics, and schema evolution automatically
- **Zero-Copy Instrumentation**: Minimal performance overhead using efficient sampling and profiling techniques
- **Real-Time Monitoring**: Observe data flows, transformations, and anomalies as they happen
- **Universal Integration**: Works with streaming platforms, databases, and custom data pipelines

## Why Enya?

Traditional observability tools tell you when a service is down. Enya tells you when your data is wrong. It answers critical questions like:

- Is my data arriving on time?
- Are schema changes breaking downstream consumers?
- Which records are failing validation?
- Where is this field being transformed in my pipeline?
- What's the actual latency of data through my system?

## Who Should Use Enya?

Enya is built for teams who need visibility into their data systems:

- **Data Engineers** building and maintaining data pipelines
- **Platform Teams** running data infrastructure at scale
- **Data Quality Teams** ensuring data reliability and accuracy
- **SREs** troubleshooting data-related incidents
- **Analytics Engineers** understanding data transformations
