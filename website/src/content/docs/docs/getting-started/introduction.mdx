# Introduction

Welcome to Enya! This introduction will help you understand what Enya is and how it can transform your observability workflows.

## What is Enya?

Enya is an AI-native observability editor that combines the power of Prometheus metrics with intelligent code analysis. It's designed for engineers who want to explore metrics efficiently using keyboard-driven workflows inspired by Neovim, while leveraging AI agents that understand both your metrics and your codebase.

## Key Features

- **AI-Native**: AI agents with access to both your Prometheus metrics and application codebase
- **Prometheus Compatible**: Works with any Prometheus-compatible endpoint with full PromQL support
- **Codebase-Aware**: Analyzes your code to identify where metrics are generated from
- **Keyboard-Driven**: Neovim-inspired workflows with h/j/k/l navigation and command palette
- **i3-Style Layouts**: Flexible tiling workspaces with splits, tabs, and custom proportions

## Why Enya?

Traditional dashboards are built for browsing. Enya is built for exploration. It answers questions like:

- Where in my code is this metric being generated?
- What changed in my codebase when this metric spiked?
- Can AI help me understand this metric behavior?
- How do I quickly navigate thousands of metrics?

## Who Should Use Enya?

Enya is built for engineers who value efficiency:

- **Backend Engineers** debugging production issues
- **SREs** investigating incidents with metric data
- **Platform Teams** exploring observability at scale
- **Anyone** who prefers keyboard-driven workflows
