# Integrations

Enya provides deep integrations with popular data systems and frameworks, offering specialized observability features tailored to each platform's unique characteristics.

## Available Integrations

Enya currently supports the following integrations:

### Apache DataFusion

Built-in observability for Apache DataFusion query engine. Track query performance, plan optimization, and execution metrics with automatic instrumentation.

[Learn more about DataFusion integration →](/docs/integrations/datafusion)

### Tokio Runtime

Native support for profiling tokio async tasks. Monitor task scheduling, resource usage, and identify async bottlenecks.

[Learn more about Tokio integration →](/docs/integrations/tokio)

## Coming Soon

- Apache Arrow
- Polars
- DuckDB
- PostgreSQL
- ClickHouse

## Custom Integrations

Enya's flexible instrumentation API makes it easy to create custom integrations for your specific data systems. See the [Custom Integrations Guide](/docs/integrations/custom) for details.
