The Problem

  • Fragmented interfaces — Metrics, SQL, terminals, others
  • Codebase-awareness — decoupled from the actual codebase that is being built and shipped
  • AI-native — not built from the ground up with AI agents in mind

What is Enya?

Neovim meets Grafana, reimagined for human and agent collaboration.

  • Multi-Tool — code, metrics, logs, traces, SQL, terminals
  • Codebase-Aware — tree-sitter analyzes your source code
  • AI-Native — agents have the same commands you do
  • Extensible — Lua plugins, custom themes

Follow along: enya.build/editor

Architecture

crates/ editor/ egui + eframe (native + WASM) datafusion/ DataFusion v51 — reuses dft analyzer/ tree-sitter (6 langs) search/ Tantivy (BM25) ai/ ACP / JSON-RPC plugin/ Lua + Rust plugins + 17 more crates

Codebase Indexing

Tree-sitter + Tantivy index your codebase to connect telemetry back to source code.

  • Metric definitions & usages — counters, gauges, histograms
  • Alert rules — Prometheus alerting from YAML
  • Labels & function context — statically extracted
  • Full-text search — BM25 ranked, sub-millisecond

AI Integration

Claude Code & Codex connect via JSON-RPC (ACP). Agents output structured commands, the editor executes them.

  • Visualize — create_pane, show_inline_chart, show_inline_table
  • Investigate — add_logs_pane, add_sql_pane, search_codebase
  • Manage — set_time_range, load_workspace, maximize_pane

Snapshots

Capture and share a workspace via URL — no data source access needed.

  • :snapshot [title] — captures all data, visualizations, agent conversations
  • Read-only — anyone with the link can view
  • Auto-expires — 7-day retention
